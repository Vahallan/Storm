```bash

./scripts/bifrost.sh init
./scripts/bifrost.sh health
```

### 2. Test Ratatoskr Queue
```bash
python3 scripts/ratatoskr.py status
python3 scripts/ratatoskr.py enqueue telemetry Veðrfölnir Níðhöggr '{"test": true}'
```

### 3. Test Urdr State Engine
```bash

python3 scripts/urdr_fountain.py sync '{"version": "1.0.1"}'
```

### 4. View Logs
```bash
tail -f .logs/bifrost.log
tail -f .logs/ratatoskr.log
```
